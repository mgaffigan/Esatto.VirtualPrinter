# Esatto.VirtualPrinter.Common

Client library for working with the Esatto Virtual Printer driver.

## SpoolFile

The `SpoolFile` class reads print job files generated by the virtual printer. It extends `Stream` and provides access to the XPS document content along with job metadata.

```csharp
await using var spoolFile = await SpoolFile.OpenAsync(jobFilePath);

Console.WriteLine($"Document: {spoolFile.DocumentName}");
Console.WriteLine($"Printer: {spoolFile.PrinterName}");
Console.WriteLine($"DataType: {spoolFile.DataType}");

// spoolFile is a Stream containing the XPS document
// Use it directly or copy to another stream
```

## VirtualPrinterSystemConfiguration

The `VirtualPrinterSystemConfiguration` class manages virtual printer installations on the system. Requires the Esatto Virtual Printer driver to be installed.

```csharp
// Enumerate existing printers (read-only)
using var config = new VirtualPrinterSystemConfiguration(PrintSystemDesiredAccess.EnumerateServer);
foreach (var printer in config.Printers)
{
    Console.WriteLine($"{printer.Name} -> {printer.TargetExe} {printer.TargetArgs}");
}

// Add a new virtual printer (requires elevation)
using var adminConfig = new VirtualPrinterSystemConfiguration(PrintSystemDesiredAccess.AdministrateServer);
adminConfig.Printers.Add(
    queueName: "My Virtual Printer",
    exePath: @"C:\MyApp\PrintHandler.exe",
    args: "--process"
);
```
